## 💡 Purpose of the Prototype

While the core logic, data structures, and mathematical validation formulas are built and executed in C (`testmint.c`), our team explored how a modern web interface could look in a commercialized deployment:
- Interactive idea submission cards
- Visual voting buttons (Interested / Pass)
- Graphical charts showing real-time validation scores
- Founder dashboard with analytics
